📖 Guía Completa de Carga de Datos

1

Formulario Manual

Agrega tareas, proyectos y etiquetas uno por uno.

📋 Campos del formulario de tareas
CampoDescripción
NombreTítulo descriptivo de la tarea. Ej: "Diseñar banner campaña Q3"
DescripciónDetalle adicional opcional. Ej: "Incluir logo y colores corporativos"
EstadoPendiente → En Progreso → En Revisión → Completado / Cancelado
PrioridadBaja (verde), Media (amarillo), Alta (rojo). Prioriza tareas críticas
AsignadoNombre de la persona responsable. Puedes escribir cualquier nombre
Fecha LímiteFecha de vencimiento. Las tareas vencidas se marcan en el calendario
ProyectoSelecciona un proyecto existente o déjalo vacío para crearlo después
EtiquetasSeparadas por coma. Se crean automáticamente si no existen. Ej: "redes, diseño, urgente"
EtapaPlanificación → Desarrollo → Revisión → Pruebas → Implementación → Seguimiento
📁 Campos del formulario de proyectos
CampoDescripción
NombreNombre del proyecto. Ej: "Campaña Marketing Q4"
DescripciónBreve resumen del objetivo del proyecto
Inicio / FinFechas del proyecto. Se ven en la línea de tiempo del dashboard
ResponsablePersona a cargo del proyecto
ColorIdentificador visual. Las tareas del proyecto heredan este color en los gráficos
🏷️ Campos del formulario de etiquetas
CampoDescripción
NombreNombre de la etiqueta. Ej: "Redes Sociales", "Desarrollo", "Urgente"
ColorColor para identificar visualmente la etiqueta en las tarjetas
DescripciónOpcional. Explica cuándo usar esta etiqueta
